    02 / UNDER THE HOOD

    From click to collection.

    01

    Route by role

    React Router wraps every page in a ProtectedRoute with allowed roles. Instructors land on Home, learners on the course catalog.

    02

    Hold the session

    Redux Toolkit stores role and user ID after login and rehydrates them from localStorage, so a refresh keeps you signed in.

    03

    Call the API

    A shared Axios instance talks to nine Express endpoints for users, courses and discussions. Multer handles profile photo uploads.

    04

    Store in MongoDB

    Mongoose models for users, courses and discussions, with bcrypt-hashed passwords and comments populated with author names.

    03 / ENGINEERING NOTES

    The details that changed the design.

    Enrolling should not copy.

    Add to Dashboard saves a full copy of the course. Copies appear in every catalog and comments land on the copy. An Enrollment model linking learner to course fixes both.

    The server has to know who's asking.

    Routes read userId and role from the query string, so access control lives in the browser. A JWT on login lets the server decide.

    Uploads need somewhere to live.

    Profile photos are saved, but the field isn't in the User schema, so Mongoose drops it. On Render's temporary disk the file would vanish anyway.

    9 API endpoints

    Users, courses and discussions across three Mongoose models.

    9 pages, 2 roles

    Role-gated routes with light and dark Material UI themes.

    Team of five

    Built with Hritik Singh, Vivek Mishra, Reva Pethe and Neha Mahangade.

    Current limitations: no server-side authentication yet, enrollments duplicate courses, profile photos don't persist, and prices are display-only. The Proposed fix mode in the demo shows a design, not code in the repository.
